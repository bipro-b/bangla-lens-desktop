# BanglaLens
Select English text anywhere (Edge PDF, Chrome, Word…) → press **Alt+B** → Bangla popup near cursor.

    npm i
    npm start            # dev
    npm run dist         # dist/BanglaLens x.y.z.exe (portable, no install)

Hotkey: change `HOTKEY` in main.js. Esc or click outside to close. Tray icon → Start with Windows / Quit.
